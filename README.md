  ### 第1–2节 导论 <a id="s1"></a>

  #### 课程概览
  以“AI 是什么、从何而来、向何处去”为主线，回顾历史里程碑，统一术语与思维框架。

  #### 学习目标
  * 理解 AI/ML/DL 的基本定义与能力范畴
  * 认识三次浪潮与典型事件（BP、ImageNet、AlphaGo、AlphaFold、GPT 等）
  * 把握数据–模型–优化的关系、训练–验证–测试流程与常见优化器

  #### 核心要点
  * AI 能做什么：识别、生成、控制、预测；线性模型、神经网络、聚类、降维、强化学习
  * 发展脉络：感知器到反向传播；GPU 与数据集驱动的突破
  * 基本范式：监督、无监督、强化；损失函数与泛化；损失景观直觉
  * 三要素：模型、数据、优化；没有免费的午餐提醒“离开数据谈算法无意义”

  ### 第3–4节 数学基础 <a id="s2"></a>

  #### 课程概览
  以线性代数、概率统计、优化为三大支柱，落到可计算的矩阵、分布与梯度方法。

  #### 学习目标
  * 熟悉向量/矩阵计算与几何直觉，理解特征值/奇异值
  * 掌握 softmax、交叉熵、KL 散度与输出分布建模
  * 理解 GD/SGD/动量/Adam 与反向传播

  #### 核心要点
  * 线代：范数、相似度、SVD 与低秩近似
  * 概率：最大似然与经验风险，分类常用交叉熵与 KL
  * 优化：学习率与鞍点影响；动量与自适应梯度；计算图与链式法则

  ### 第5–6节 高维数据与维数灾难 <a id="s3"></a>

  #### 课程概览
  理解高维空间的稀疏与集中现象以及由此带来的样本与计算负担，并给出常见缓解路径。

  #### 学习目标
  * 认识体积/距离/角度的集中与近正交
  * 理解维数灾难在积分、PDE、逼近中的表现
  * 了解蒙特卡洛、随机投影、特定函数类中的可效表达

  #### 核心要点
  * 现象：高斯环带、距离与夹角集中、线性可分性变化
  * 代价：网格节点与参数量随维数指数增长
  * 解法：蒙特卡洛误差与维数无关；JL 投影；神经网络在 Barron/组合函数空间的高效逼近

  ### 第7–8节 传统监督学习 <a id="s4"></a>

  #### 课程概览
  统一“数据→表示→模型→损失→优化→评估”链路，覆盖线性模型、决策树与支持向量机。

  #### 学习目标
  * 区分回归与分类任务
  * 掌握线性回归/逻辑回归/LDA 与多分类拆解策略
  * 理解决策树生成–剪枝与多变量划分
  * 把握 SVM 的最大间隔思想与核技巧

  #### 核心要点
  * 线性模型：正规方程/梯度法；交叉熵与最大似然；LDA 的投影判别
  * 决策树：信息增益/基尼；停止与剪枝；可解释性与不稳定性
  * SVM：软间隔、Hinge 损失；核函数实现非线性分割
  * 方法比较：正则化、偏差–方差、数据不平衡与评估指标

  ### 第9–10节 传统无监督学习 <a id="s5"></a>

  #### 课程概览
  在无标签数据中挖掘潜在结构与低维表征：聚类、降维、密度与邻域视角。

  #### 学习目标
  * 明确聚类与降维的目标与评价
  * 掌握 K-means、GMM+EM 及其局限
  * 区分线性 PCA 与基于距离/流形的非线性降维（MDS/ISOMAP/t-SNE）

  #### 核心要点
  * 聚类：距离度量选择、簇内紧致与簇间分离、模型假设与初始化敏感性
  * 降维：PCA 的方差最大/重构最小等价；ISOMAP 的测地线保持；t-SNE 的邻域概率保持与可视化用途
  * 实践要点：特征缩放、选 k、随机性与多次运行、可视化诊断

  ### 第11–12节 全连接与残差网络 <a id="s6"></a>

  #### 课程概览
  从“线性变换+非线性激活”的 MLP 出发，引出残差连接缓解深层退化与梯度消失。

  #### 学习目标
  * 理解单元/多层表达与 XOR 案例
  * 掌握交叉熵与困惑度、常见初始化方法
  * 认识 ResNet 的前向/反向形式与梯度直通

  #### 核心要点
  * 表示能力：两层网络的万有逼近基线与“可逼近≠易训练”
  * 初始化与激活：方差稳定、饱和问题与 ReLU 家族
  * 残差块：y=x+F(x) 的捷径路径与梯度公式；瓶颈结构、归一化与调参要点

  ### 第13–14节 卷积网络 <a id="s7"></a>

  #### 课程概览
  从图像统计与不变性到 CNN 设计动机，涵盖卷积、步幅、填充、池化与多通道等核心算子。

  #### 学习目标
  * 理解平移等变与近似不变及其对泛化与数据效率的影响
  * 掌握卷积层与池化层的前向与反向传播要点
  * 了解典型数据集与实验设置

  #### 核心要点
  * 统计与启发：空间相关、频谱幂律；V1 简单/复杂细胞对应卷积与聚合
  * 卷积运算：局部连接、权共享、输出形状计算
  * 池化：最大/平均与梯度回传；全局平均池化减少参数

  ### 第15–17节 循环神经网络 <a id="s8"></a>

  #### 课程概览
  聚焦序列建模与语言任务，引入 NTP 框架与 RNN/LSTM 的计算与训练。

  #### 学习目标
  * 了解词元化与特殊符号
  * 掌握 RNN 的递推与 BPTT、梯度消失/爆炸与裁剪
  * 理解 LSTM 门控与 Encoder–Decoder 框架

  #### 核心要点
  * 语言模型：以交叉熵训练下一个词元预测，推理用贪婪或采样
  * RNN 基础：h_t 递推与并行性的限制
  * LSTM：细胞状态与门控的稳定路径；与残差直通的类比
  * 实践案例：字符级生成、IMDB 情感、Kaggle 练习

  ### 第18–20节 Transformer <a id="s9"></a>

  #### 课程概览
  以注意力为核心替代循环依赖，实现全局建模与高并行，覆盖 Encoder–Decoder 与 Decoder-only 两种范式。

  #### 学习目标
  * 掌握多头自注意力、位置编码、LayerNorm 与残差堆叠
  * 理解 NTP 训练与常用解码策略
  * 认识 ViT 与科学计算等拓展

  #### 核心要点
  * 组件：Embedding+位置编码，MHA（Q/K/V 与因果 Mask），FFN，残差与归一化
  * 训练与推理：交叉熵与温度、Top-k/Top-p 采样
  * 拓展：RoPE/ALiBi 的长度外推；视觉与蛋白质结构建模

  ### 第21–22节 训练过程中的典型现象 <a id="s10"></a>

  #### 课程概览
  从函数空间、参数空间与损失景观三个视角梳理常见规律。

  #### 学习目标
  * 认识频率原则与早停的泛化意义
  * 理解小初始化下的参数凝聚与“有效小网络”
  * 把握平坦最小值、稳定边缘与训练技巧

  #### 核心要点
  * 频率原则：先学低频后学高频，早停可防过拟合细噪声
  * 凝聚现象：参数趋同聚集，宽网络易优化且包含窄网络解
  * 平坦性：小批量与合适较大学习率有助于到达平坦解；正则与数据增广有效
